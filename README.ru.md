## ✨ Зачем это нужно

Inferbase — это обычный OpenAI-совместимый шлюз (`https://api.inferbase.ai/v1`), регистрация в котором представляет собой **регистрацию с защитой Turnstile и подтверждение по ссылке из письма**. Новый аккаунт получает **100 запросов за календарный день по UTC** на собственных моделях Inferbase — этого достаточно для реальной нагрузки, а счётчик сбрасывается в **00:00 UTC**, а не истекает. Один аккаунт содержит **один ключ** (`auto_scope: inferbase`, `rate_limit_rpm: 6`). Инструмент управляет **настоящим Chrome с графическим интерфейсом** через CDP, поскольку виджет Cloudflare создаётся только там, и он ничего не тратит на выход, виджет которого не отвечает.

## 🎁 Бесплатный тариф — сколько вы получаете

| Что | Значение |
| --- | --- |
| Бесплатная квота | **100 запросов за календарный день по UTC на аккаунт (организацию)** на собственных моделях Inferbase |
| Сброс | **00:00 UTC** — измерено: исчерпанный счётчик ответил `402 Free plan limit: 100 requests per UTC day … all used`, а тот же ключ ответил `200` после сброса |
| Лимиты тарифа (от провайдера) | 5000 запросов/месяц · 100 управляемых запросов/день · $0.50/день управляемых |
| Лимит скорости на ключ | `rate_limit_rpm: 6` (возвращается при создании ключа) |
| Карта / телефон | **нет** — ни шага оплаты, ни номера телефона не запрашивается |
| Ключей на аккаунт | **1** (инструмент создаёт один ключ на аккаунт) |

> 💡 Бесплатный тариф устанавливается Inferbase и может измениться. Проверяйте актуальные цифры на [inferbase.ai](https://inferbase.ai) — и позвольте собственному гейту инструмента решить:

```bash
node src/cli.js --verify-only     # каждый ключ в keys.txt повторно тестируется реальным вызовом чата
```

## 🤖 Модели — все 127

Эндпоинт объявляет **127 идентификаторов**; `GET /v1/models` возвращает ровно то, что аккаунт может вызывать, а `auto` маршрутизирует к живой модели (измерено: `auto` ответил как `qwen3-8-max`).

| ID модели | примечание |
| --- | --- |
| `auto` | маршрутизатор — значение по умолчанию, по которому инструмент выполняет проверку |
| `qwen3-8-max` | то, к чему разрешился `auto` в измеренных запусках |
| `deepseek-v4-flash`, `deepseek-v4-pro` | чат, вызов инструментов проверен |
| `meta-llama-3-1-8b-instruct`, `bytedance-seed-2-0-*` | другие текстовые маршруты |

Идентификаторы изображений (`bfl-flux-*`) и `deepseek-ocr-2` также перечислены, но не являются чат-маршрутами; гейт инструмента всегда использует `auto`.

## 🧪 Как использовать API

Базовый URL **`https://api.inferbase.ai/v1`** — OpenAI-совместимый. Ключи состоят из 52 символов, с префиксом `inf_`.

```bash
curl https://api.inferbase.ai/v1/chat/completions \
  -H "Authorization: Bearer YOUR_KEY…" -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Say OK."}],"max_tokens":16}'
```

```python
from openai import OpenAI
c = OpenAI(base_url="https://api.inferbase.ai/v1", api_key="YOUR_KEY…")
print(c.chat.completions.create(model="auto",
      messages=[{"role": "user", "content": "Say OK."}], max_tokens=16).choices[0].message.content)
```

## ⚡ Одна команда

```bash
node src/cli.js --count N        # N аккаунтов → N ключей, одна команда, ничего отвечать не нужно
```

Виджет Cloudflare Turnstile создаётся встроенным движком браузера (`src/solver.js`) в настоящем Chrome с **графическим интерфейсом** — `--auto` включён **по умолчанию** и остаётся включённым, так что капчу вставлять не нужно и вопрос о браузере не возникает. Указание `--dry` выводит разрешённый план (количество, модель, маршрут, решатель, путь к Chrome) и завершается с кодом 0, не записывая файл и не открывая сокет:

```bash
node src/cli.js --count N --dry
```

`npm start` (или `node src/launcher.js`) делает то же самое из меню: выберите **1) Mint keys**, ответьте на «How many keys?» (Enter = 10), и он выполнит `node src/cli.js --auto --count N`. `proxies.txt` подхватывается автоматически, если он существует, иначе запуск идёт напрямую.

## 🛠 Быстрый старт

```bash
cd inferbase-bulk-apikey
printf 'socks5://host:port\n' > proxies.txt   # необязательно — без него инструмент работает напрямую
node src/launcher.js        # интерактивно: создание / проверка / отбор
# или напрямую:
node src/cli.js --count 1        # одна регистрация + подтверждение по e-mail в настоящем Chrome
node src/cli.js --verify-only    # повторно протестировать каждый ключ, уже имеющийся в keys.txt
node src/cli.js --screen         # HTTP-отбор списка выходов
```

Для регистрации нужен настоящий Chrome с **графическим интерфейсом**: виджет Turnstile создаётся только там, и поток отказывается регистрироваться на выходе, виджет которого не отвечает. `keys.txt` записывается только после того, как на этом ключе был получен реальный ответ на запрос завершения.

### 🖱️ Лаунчер

`node src/launcher.js` — это меню над теми же модулями: **создание**, **проверка**, **отбор**, **9Router**, **настройки**. Настройки сохраняются в `launcher.config.json`.

## ✅ Проверено в работе — каждый ключ протестирован

Измерено **2026-10-23** из поставляемого CLI (список выходов, без WARP).

| Проверка | Результат |
| --- | --- |
| проверка выхода (HTTP) | страница входа + скрипт Turnstile + API доступны |
| отбор Chrome (в потоке) | строка, виджет которой никогда не создаётся, отклоняется **до** того, как будет израсходован почтовый ящик |
| регистрация | `POST /api/v1/auth/register` → **200** `Account created` |
| подтверждение по e-mail | письмо от `hello@inferbase.ai` → `?token=` → `POST /api/v1/auth/verify-email` → **200** `Email verified successfully.` |
| ключ | `POST /api/v1/inference/keys` (X-CSRF-Token) → **201/200**, 52-символьный `inf_…` |
| гейт чата | `POST /v1/chat/completions` `auto` → **200** `OK.` |
| гейт инструментов | схема инструмента `get_time` в запросе → `tool_calls` в ответе |
| живой гейт | каждый ключ в `keys.txt` прошёл живой `chat-200` перед поставкой; CLI также создаёт свежий ключ от начала до конца в качестве самопроверки |

> **Контроль качества.** Каждый ключ здесь прошёл живой `chat-200` перед тем, как был записан в `keys.txt`
> (мёртвые ключи никогда не поставляются). Комбинации маршрутизатора следуют тому же правилу на уровне модели: запись
> добавляется **только если модель отвечает `chat-200` и может вызывать инструменты** — модель без поддержки инструментов,
> мёртвый ключ или мёртвый провайдер отбрасывается вместо добавления. Повторно запускайте шаг проверки в любое время;
> сбои сообщаются, никогда не скрываются.

## 🧭 Как это работает

```
inbox (один адрес на аккаунт)                                  новый адрес на каждый аккаунт
   │
   ├─▶ регистрация: страница Inferbase → адрес e-mail → код / ссылка из inbox
   ├─▶ сессия: cookie аккаунта или токен доступа на руках
   ├─▶ создание ключа: эндпоинт ключа аккаунта → открытый ключ возвращается один раз (немедленно записывается на диск)
   └─▶ живое подтверждение: POST https://api.inferbase.ai/v1/chat/completions → реальный контент = ключ живой
```

| Шаг | Вызов | Примечания |
| --- | --- | --- |
| отбор | страница регистрации в Chrome | виджет должен смонтироваться **и** создаться; больше ничего не тратится на строку, которая не может |
| почтовый ящик | `temp.tf` (`providers=gmail`) | публичный API, без ключа; панель отправляет письма от `hello@inferbase.ai` |
| регистрация | `POST /api/v1/auth/register` | `{email,password,full_name,company,turnstile_token}` — токен должен прийти с того же выхода |
| подтверждение | `POST /api/v1/auth/verify-email` | письмо содержит `?token=` |
| вход | `POST /api/v1/auth/login` | устанавливает cookie сессии и `csrf_token` |
| ключ | `POST /api/v1/inference/keys` | изменяющий маршрут → требуется `X-CSRF-Token` (403 `CSRF token missing` без него) |
| гейт | `GET /v1/models` + запрос завершения | сохраняется только реальный 200 с контентом |

## ⚙️ Опции CLI

```bash
node src/cli.js --count 5                  # пять регистраций, последовательно
node src/cli.js --model auto
node src/cli.js --verify-only              # повторно проверить keys.txt
node src/cli.js --screen                   # HTTP-отбор списка выходов
node src/cli.js --connect-9router          # зарегистрировать провайдера + ключи на локальном 9Router
node src/cli.js --help
```

| Флаг | По умолчанию | Значение |
| --- | --- | --- |
| `--count N` | `1` | количество аккаунтов для создания, последовательно |
| `--model <id>` | `auto` | модель, используемая для живого гейта |
| `--pool <file>` | `proxies.txt` | список выходов, одна строка на прокси — необязательно |
| `--exits N` | `6` | кандидаты выходов, отбираемые на аккаунт |
| `--mint-tries N` | `2` | полные попытки регистрации (новый почтовый ящик) на выход |
| `--code-timeout S` | `240` | секунды ожидания письма с подтверждением |
| `--keys <file>` | `keys.txt` | файл ключей для `--verify-only` / `--connect-9router` |
| `--headless` | выкл. | ТОЛЬКО ДЛЯ ДИАГНОСТИКИ — виджет не будет создан |

## 🛰️ За прокси

**Необязательно — рекомендуется при масштабировании (лимиты на IP, блокировки).** Инструмент работает и без прокси.

- **С пулом:** передайте `--pool <file>` (или задайте `INFERBASE_PROXIES`), и каждый запрос — включая браузер Chrome — идёт через выход из этого списка, с отказом при ошибке.
- **Без пула:** CLI выводит режим `direct` и подключается напрямую; регистрация, создание ключей и гейт не меняются.
- Качество выходов определяет успех: отбор Chrome в потоке отклоняет строку, виджет Turnstile которой никогда не создаётся, до того как будет израсходован почтовый ящик.

## 🔌 Подключение к 9Router

[9Router](https://9router.com) — это самостоятельно размещаемый OpenAI-совместимый маршрутизатор:

```bash
node src/connect-9router.js --base http://localhost:20128 --password 123456
```

По умолчанию: `--prefix inferbase`, `--base-url https://api.inferbase.ai/v1`, `--model auto`. Модели предоставляются как `inferbase/<model id>`. CLI может сделать то же самое одной командой: `node src/cli.js --connect-9router`.

## ⚠️ Условия и риск для аккаунта

Этот инструмент автоматизирует процесс регистрации, поэтому **вы** несёте ответственность за то, что он делает: автоматизация регистрации у провайдера может нарушать условия обслуживания этого провайдера, а бесплатный тариф, который предоставляет аккаунт, принадлежит провайдеру, который может его ограничивать, изменять или отзывать в любое время — на аккаунт и на IP. Используйте его только для аккаунтов, которые вам разрешено создавать, храните свой список прокси при себе и не рассматривайте эти ключи как производственную мощность. Ничто здесь не является разрешением обходить правила провайдера.

## 🐞 Проблемы

Если Inferbase изменит форму своей регистрации, ключ сайта Turnstile (`0x4AAAAAAEE8v-wpU5kytU0i`), ежедневную квоту в 100 запросов или каталог моделей, инструмент остановится на этом шаге и сообщит об этом. **[Откройте issue](../../issues)** с командой и точным выводом.
